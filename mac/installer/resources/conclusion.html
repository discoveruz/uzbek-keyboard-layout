Klaviaturalar oʻrnatildi

Klaviaturani yoqish uchun:

  1. Tizimdan chiqib, qayta kiring (Apple menu → Log Out). Shundan keyingina macOS yangi klaviaturalarni koʻradi.
  2. System Settings → Keyboard ni oching.
  3. Text Input boʻlimida Input Sources yonidagi Edit… ni bosing.
  4. Pastdagi + ni bosing va Uzbek ni tanlang.
  5. Uzbek Latin 2026 (…) dan birini tanlab, Add ni bosing.

Klaviaturalar orasida 🌐 (fn) yoki Control + Space bilan almashasiz. Windowsdagi AltGr oʻrniga Macda Option (⌥) ni bosing.

The layouts are installed

To turn one on:

  1. Log out and back in (Apple menu → Log Out). macOS only finds new layouts after that.
  2. Open System Settings → Keyboard.
  3. Under Text Input, click Edit… next to Input Sources.
  4. Click + at the bottom and choose Uzbek.
  5. Pick one of the Uzbek Latin 2026 (…) layouts and click Add.

Switch between keyboards with 🌐 (fn) or Control + Space. Where Windows uses AltGr, press Option (⌥) on a Mac.
